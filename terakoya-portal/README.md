# 寺子屋ポータル — 公開版ソースコード

公開版に対応するソースを、利用者データ・秘密設定を含めずに書き出したものです。別のアバター試作品や未公開の変更は含みません。

## GitHubへ載せる手順

1. ZIPをパソコンで展開します。
2. GitHubで新しいリポジトリを作ります。
3. 展開したフォルダーの中身をアップロードします。ZIP自体だけを載せるとコードが閲覧しにくくなります。
4. ファイルが多いため、ブラウザで一括アップロードできない場合はGitHub Desktopでフォルダーをリポジトリとして追加します。

`.gitignore`や`.openai/hosting.json`など先頭がドットのファイルも含めてください。ただし、今後作る`.env`や`.dev.vars`、DB実体は載せないでください。設定例`.dev.vars.example`の値は空です。

## 同じ機能を動かすために必要なもの

GitHubへのアップロードはコードの保管です。GitHub Pagesだけでは、このサイトのログイン・PON・ゲーム・投稿などのサーバー処理は動きません。

公開版はVinext／React、Cloudflare Workers、D1データベース、Sitesの認証サービスを使用しています。同じ機能にはこれらに対応する実行環境と、新しい環境での設定が必要です。利用者、PON残高、投稿、申請履歴、アンケート回答などは移していないため、データは空から始まります。現在のランキングや画面の数値まで同じになるバックアップではありません。

## 内容

- `app/`：画面・寮診断・科目一覧・占い・ゲーム・PON・プロフィール・管理API
- `public/`：公開版の画像・アイコン
- `worker/`：サーバー入口
- `db/`：接続とテーブル定義
- `drizzle/`：マイグレーション・スキーマ情報（利用者の実データではありません）
- `package.json`・`package-lock.json`：依存ライブラリと固定バージョン
- `vite.config.ts`・`build/`・`scripts/`ほか：開発・ビルド設定
- `EXPORT-NOTES.md`：元ソース・変更・除外事項・確認範囲

## 開発・ビルド

Node.js 22.13.0以上が必要です。

```sh
npm ci
npm exec vinext build
```

開発サーバーは次で起動します。

```sh
npm exec vite
```

`npm run build`は元のLinux向け補助スクリプトを使います。WindowsはWSL、macOSはGNU timeoutなどが必要です。上の直接ビルドは補助スクリプトを経由しません。開発サーバーの起動だけではログイン環境は用意されません。

## 新しい実行環境の構成

1. Sites／Cloudflare Workers対応環境を用意します。
2. D1データベースを新規作成し、`DB`でバインドします。
3. `drizzle/meta/_journal.json`の順番でマイグレーションを適用します。新規の空DB向けです。既存DBへの適用はデータ変更を伴うため、そのまま流用しないでください。
4. 認証サービスを構成します。公開版ではSitesが`/signin-with-chatgpt`・`/signout-with-chatgpt`・`/callback`と認証済みヘッダーを提供します。このサービス実装はホスティング基盤の機能であり、リポジトリに含まれません。別基盤では安全な認証連携への置き換えが必要です。外部から任意に送られた認証ヘッダーを信頼してはいけません。
5. サーバー環境変数`ADMIN_EMAIL`に管理者のログインメールを設定します。値はホスティング側で管理し、コードに書かないでください。未設定では管理者の初期登録ができません。
6. 新しいSitesへ配置する場合、`.openai/hosting.json`のプロジェクト識別子は新しい環境で割り当てます。元サイトの識別子は除去しています。
7. 新しい環境で登録・診断・申請・承認・ゲーム・投稿を確認します。

`vite.config.ts`の全ゼロのDB識別子は開発用ダミーであり、本番接続先ではありません。

## 除外したもの

Git履歴、認証情報、APIキー、管理者の実メールアドレス、環境変数の実値、DBダンプ、利用者記録、ログ、キャッシュ、node_modules、ビルド済み出力は含めていません。メール等のフィールド名と寮・ゲームの名称は機能定義として残しています。

今後追加する秘密設定や利用者データはリポジトリに入れないでください。この書き出しは新たなオープンソースライセンスを付与するものではありません。
